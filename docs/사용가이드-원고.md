# 프로모션 퍼블 자동 생성기 — 사용 가이드

프로모션 페이지의 반복적인 퍼블리싱 작업을 자동화하는 도구입니다.
이미지 URL과 버튼 위치만 입력하면 PC·모바일용 HTML 코드를 만들어 줍니다.

주소: https://pub-maker-drab.vercel.app/

> 이 문서는 실제 화면을 따라가며 읽도록 쓰였습니다.
> `[스크린샷 N]` 표시가 있는 곳에 해당 번호의 화면 이미지를 넣어 보세요.

---

## 1. 이 도구가 하는 일

프로모션 페이지는 대부분 **디자인 이미지 한 장(또는 여러 장)** 위에
**투명한 클릭 영역**을 얹어 만듭니다. 버튼처럼 보이는 것은 사실 이미지의 일부이고,
그 위에 눈에 보이지 않는 `<a>` 태그가 정확한 위치에 겹쳐 있는 구조입니다.

이 작업은 좌표를 일일이 재고 % 로 환산해야 해서 손이 많이 갑니다.
이 도구는 그 과정을 **드래그 한 번**으로 바꿔 줍니다.

| 직접 할 때                         | 이 도구로 할 때           |
| ---------------------------------- | ------------------------- |
| 이미지에서 버튼 좌표를 픽셀로 측정 | 화면에서 박스를 드래그    |
| 픽셀 → % 환산 계산                 | 자동                      |
| PC·모바일 좌표를 각각 계산         | 플랫폼만 바꾸면 자동 환산 |
| HTML 을 손으로 작성                | `코드 생성하기` → `복사`  |

**만들어 주지 않는 것**도 알아 두면 좋습니다. 이 도구는 **클릭 영역과 구조만**
만듭니다. 버튼 모양, 탭 메뉴 그림, 배너 디자인은 **이미지 안에 이미 그려져 있어야** 합니다.

## 2. 5분 만에 첫 코드 만들기

가장 단순한 작업 하나를 끝까지 해 봅니다. **이미지 한 장에 버튼 하나**를 얹습니다.

1. `투어비스(항공일반)` 탭에서 시작합니다
2. **플랫폼**을 `💻 PC` 로 둡니다
3. **이미지 URL** 칸에 이미지 주소를 붙여 넣고 **다른 곳을 클릭**합니다
   (포커스를 빼야 원본 크기를 읽습니다 — 뒤에서 다시 설명합니다)
4. 오른쪽 미리보기에 이미지가 뜨는지 확인합니다
5. 이미지 행 아래 **`+ 버튼`** 을 누릅니다
6. 생긴 요소 상자에서 **`영역 설정하기`** 를 누릅니다
7. 이미지 위 파란 박스를 **버튼 자리로 드래그**하고, **모서리 핸들로 크기**를 맞춥니다
8. **`적용`** 을 누릅니다 → 버튼이 **초록색 `✅ 영역 설정 완료`** 로 바뀝니다
9. 요소 타입을 고르고 값을 넣습니다 (예: `항공권 예약하기` + 항공사 코드 `7C`)
10. 맨 아래 **`🚀 코드 생성하기`** → **`복사`**

이것이 전부입니다. 나머지 기능은 모두 이 흐름의 변주입니다.

## 3. 화면 구성

화면은 크게 셋입니다.

**상단 탭** — 어떤 채널의 코드를 만들지 고릅니다 (투어비스 / 베네피아·휴가샵 / SKT)

**왼쪽 패널 — `1. 설정`** — 모든 입력을 여기서 합니다.
기능 블록이 구분선으로 나뉘어 있고, 제목 앞에 세로 막대가 있습니다.

- 이미지 정보 입력
- 이미지맵 영역 추가 _(베네피아·SKT)_
- 앵커 영역 설정 _(베네피아·SKT)_
- 탭 스크롤
- 스티키 탭
- 탭 콘텐츠 전환

**오른쪽 패널 — `2. 결과 확인`** — 미리보기와 생성된 코드

[스크린샷 6] 왼쪽 설정 패널 전체 (구분선이 보이도록)

### 미리보기와 코드는 갱신 시점이 다릅니다

| 영역        | 갱신 시점                                  |
| ----------- | ------------------------------------------ |
| 미리보기    | 입력할 때마다 **자동**                     |
| 코드 텍스트 | **`🚀 코드 생성하기` 를 눌러야** 확정 갱신 |

작업이 끝나면 **반드시 `코드 생성하기` 를 누른 뒤 복사**하세요.
미리보기만 보고 이전 코드를 복사하는 것이 가장 흔한 실수입니다.

## 4. 세 개 탭 중 무엇을 쓸까

기능은 세 탭이 거의 같습니다. 차이는 **출력 형식**과 **작업 관행**입니다.

| 탭                     | 이미지 관행                       | 영역 지정 방식                  | 출력                        |
| ---------------------- | --------------------------------- | ------------------------------- | --------------------------- |
| **투어비스(항공일반)** | 섹션마다 이미지를 **나눠서** 등록 | 요소마다 **매퍼 창**에서 드래그 | 완결된 HTML 문서            |
| **베네피아/휴가샵**    | **통이미지 1장**에 전부 배치      | 미리보기에서 **직접 드래그**    | HTML 조각                   |
| **SKT**                | 통이미지 1장                      | 미리보기에서 **직접 드래그**    | HTML 조각 (SKT 관리자 규격) |

- **완결된 HTML 문서**는 `<!DOCTYPE html>` 부터 들어 있어 그대로 파일로 저장하면 열립니다
- **HTML 조각**은 게시 시스템의 본문 편집기에 붙여 넣는 용도입니다

세 탭 모두 이미지를 여러 장 등록할 수 있습니다. 위 구분은 **기능 제약이 아니라 관행**입니다.

### 탭별 고유 기능

- **투어비스** — 플랫폼(PC/모바일) 전환, 배경색 지정, 항공권 예약 버튼
- **베네피아** — 쿠폰 다운로드 버튼
- **SKT** — SKT 관리자 규격 탭 링크, 링크 투명화 스타일 자동 삽입

## 5. 반드시 알아야 할 것

### 5.1 좌표는 전부 % 입니다

생성되는 좌표는 픽셀이 아니라 **이미지 대비 %** 입니다.
그래서 브라우저 폭이 바뀌어도 버튼이 이미지를 따라다닙니다.

이미지를 교체할 때 **가로세로 비율만 같으면** 좌표를 다시 잡지 않아도 됩니다.
반대로 비율이 달라지면 전부 다시 잡아야 합니다.

### 5.2 이미지 URL 은 입력 후 포커스를 빼세요

URL 칸에서 **Tab 키를 누르거나 다른 곳을 클릭**해야 원본 이미지 크기를 읽어옵니다.
이 값은 **mp4 영상의 화면 비율 계산**과 좌표 환산에 쓰입니다.

입력만 하고 바로 영상을 추가하면 비율이 어긋납니다.

### 5.3 클릭 영역은 투명하지만 커서가 바뀝니다

만들어지는 링크는 **이미지 위에 얹는 투명한 영역**이라 눈에 보이지 않습니다.
대신 마우스를 올리면 **손 모양 커서**로 바뀌어 누를 수 있는 자리임을 알려 줍니다.
쿠폰 다운로드, 링크, 앵커 이동, 탭, 항공권 예약, 앱 알림 설정 모두 그렇습니다.

**섹션 시작점만 예외**입니다. 앵커가 도착할 지점일 뿐 누르는 대상이 아닙니다.

### 5.4 이미지에 없는 것은 만들어지지 않습니다

버튼 모양, 탭 메뉴 그림은 **이미지에 이미 그려져 있어야** 합니다.
이 도구는 그 위에 얹을 **투명한 클릭 영역**만 만듭니다.

## 6. 영역 지정하기

### 6.0 어디서 편집하는지가 탭마다 다릅니다

**가장 헷갈리는 부분**이니 먼저 짚고 갑니다.

| 탭             | 영역·앵커를 옮기는 곳                                     |
| -------------- | --------------------------------------------------------- |
| 투어비스       | **왼쪽 패널 아래**에 열리는 매퍼 창                       |
| 베네피아 / SKT | **오른쪽 미리보기 이미지 위** — 별도 창이 열리지 않습니다 |

베네피아·SKT에서 `+ 앵커 이동`, `+ 링크`, `+ 새 앵커 추가` 를 눌렀는데
**왼쪽에 아무 창도 안 뜬다고 실패한 것이 아닙니다.** 오른쪽 미리보기를 보세요.
거기에 영역 상자나 빨간 핀이 이미 놓여 있습니다.

왼쪽 목록은 **종류와 값**만, 오른쪽 미리보기는 **위치와 크기**를 담당합니다.

### 6.1 투어비스 — 매퍼 창

요소의 `영역 설정하기` 를 누르면 왼쪽에 매퍼가 열립니다.

- 매퍼 제목에 **편집 중인 요소**가 표시됩니다 (`2. 영역 설정 — 요소 #2 · 앵커 이동 → #a`)
- 파란 박스를 **드래그해 위치**를 잡고, **모서리 핸들로 크기**를 맞춥니다
- **`적용` 을 눌러야 저장**됩니다

### 6.2 베네피아 · SKT — 미리보기에서 직접

- 미리보기 이미지 위에서 **바로 드래그**하면 영역이 생깁니다
- 가로·세로 모두 **10px 이상** 끌어야 생성됩니다
- 만든 영역은 **드래그로 이동**, **8방향 핸들로 크기 조절**, **× 로 삭제**
- 이미지가 여러 장이면 편집 표시는 **활성 이미지 1장에만** 나옵니다.
  왼쪽 이미지 행을 클릭해 활성 이미지를 바꿉니다

### 6.3 버튼 색이 진행 상태를 알려 줍니다 (투어비스)

| 색      | 문구                       | 뜻                                                |
| ------- | -------------------------- | ------------------------------------------------- |
| 🟦 남색 | `영역 설정하기`            | 아직 좌표 없음 — 지정해야 코드가 생성됩니다       |
| 🟧 주황 | `📍 기본 영역 — 조정 필요` | 세트가 넣은 **임시 좌표** — 실제 위치로 옮겨야 함 |
| 🟩 초록 | `✅ 영역 설정 완료`        | 직접 지정하고 `적용` 까지 누름                    |

**주황이 남아 있으면 아직 손대지 않은 요소**입니다. 코드는 생성되지만 위치가 엉뚱합니다.

[스크린샷 7] 남색·주황·초록 버튼이 함께 보이는 상태

## 7. 요소 종류

### 7.1 투어비스

| 버튼            | 만들어지는 것                                  |
| --------------- | ---------------------------------------------- |
| `+ 버튼`        | 항공권 예약하기 / 단순 링크                    |
| `+ 영상`        | 유튜브 또는 mp4 영상                           |
| `+ 앵커 이동`   | `<a href="#섹션ID">` — 같은 페이지 안에서 점프 |
| `+ 섹션 시작점` | 앵커가 도착할 지점                             |
| (타입 변경)     | **앱 알림 설정** — 투어비스 앱 전용 (§9-2)     |

| 타입            | 입력값                                    |
| --------------- | ----------------------------------------- |
| 항공권 예약하기 | 항공사 코드 (예: `7C`, `KE`)              |
| 단순 링크       | 연결 URL, 열기 방식 (새 창 / 현재 페이지) |
| 앵커 이동       | 이동할 섹션 ID (예: `a`)                  |
| 섹션 시작점     | 섹션 ID — **시작점(세로 위치)만** 사용    |

### 7.2 베네피아

| 타입          | 쓰임                                      |
| ------------- | ----------------------------------------- |
| 링크          | 외부/내부 페이지 이동                     |
| 쿠폰 다운로드 | 쿠폰 ID 를 **쉼표로 구분**해 여러 개 가능 |
| 앵커 이동     | 같은 페이지 안 점프                       |
| 영상          | 유튜브 / mp4                              |

> 쿠폰 내려받기 함수는 **게시 페이지에 이미 있다고 가정**합니다.
> 이 도구는 호출하는 부분만 만듭니다.

### 7.3 SKT

링크 / 앵커 이동 / **탭** / 영상 (쿠폰 없음).
`탭` 은 SKT 관리자 규격에 맞춘 형태로 나가고, 링크를 투명하게 만드는
스타일이 **문서 앞에 한 번** 자동으로 붙습니다.

## 8. 투어비스 플랫폼과 최대 폭

### 8.1 PC 와 모바일은 결과가 다릅니다

- 항공권 예약 버튼의 **호출 함수**가 다릅니다
- **래퍼 규격**이 다릅니다 — PC 는 최대 1200px, 모바일은 최대 900px (둘 다 가운데 정렬)

### 8.2 최대 폭 입력

플랫폼 선택 옆에서 조정합니다.

- **플랫폼별로 값을 따로 기억**합니다 — PC 를 1000 으로 바꾸고 모바일에 갔다 돌아와도 1000 유지
- `초기화` 를 누르면 기본값으로 돌아갑니다

### 8.3 배경색을 넣으면 좌우 여백이 생깁니다

PC 에서 **흰색이 아닌 배경색**을 지정하면 좌우에 여백이 붙습니다
(래퍼 폭의 1/6씩, 그래서 이미지는 래퍼의 2/3 폭).

이때 **가로 좌표가 자동으로 환산**됩니다. 같은 위치인데 값이 달라 보이는 것이 정상입니다.

|        | 좌우 여백 | 이미지 실폭 | 출력 좌표                |
| ------ | --------- | ----------- | ------------------------ |
| 모바일 | 없음      | 래퍼와 동일 | `left: 5%` `width: 90%`  |
| PC     | 있음      | 래퍼의 2/3  | `left: 20%` `width: 60%` |

세로 좌표는 위아래 여백이 없으므로 그대로입니다.

[스크린샷 8] PC + 배경색 + `버튼 영역 시각화` 를 켠 미리보기

## 9. 영상 넣기

이미지 위 원하는 위치에 **유튜브** 또는 **mp4** 영상을 겹쳐 넣습니다.

### 9.1 절차

| 탭             | 절차                                                              |
| -------------- | ----------------------------------------------------------------- |
| 투어비스       | `+ 영상` → `영역 설정하기` 로 위치·크기 지정 → `적용` → URL 입력  |
| 베네피아 / SKT | `+ 영상` → 미리보기의 **VIDEO 박스**를 드래그·리사이즈 → URL 입력 |

### 9.2 유튜브

주소는 어떤 형태로 넣어도 인식합니다.

```
https://www.youtube.com/watch?v=영상ID
https://youtu.be/영상ID
https://www.youtube.com/embed/영상ID
https://www.youtube.com/shorts/영상ID
영상ID (11자리)
```

옵션은 **자동재생 · 음소거 · 반복 · 컨트롤 표시** 네 가지입니다.

> **자동재생을 켰는데 재생이 안 된다면 음소거를 확인하세요.**
> 브라우저는 소리 있는 자동재생을 막습니다.

### 9.3 MP4

`확대 비율` 이 추가로 있습니다. **100 을 넘으면 영상의 위아래가 잘립니다** —
영상 자체의 여백을 잘라내고 화면을 꽉 채우고 싶을 때 씁니다.

MP4 는 이미지 원본 크기로 화면 비율을 계산하므로,
**이미지 URL 을 넣고 포커스를 뺀 뒤에** 영상을 추가해야 합니다.

## 9-2. 앱 알림 설정 (투어비스 앱 전용)

버튼을 누르면 **투어비스 앱의 알림 설정 화면**이 열립니다.
요소 타입을 `앱 알림 설정` 으로 바꾸면 됩니다.

입력값은 **앱 설치 링크** 하나뿐입니다 (예: `https://abr.ge/uysf2c`).
앱이 아닌 환경에서 보낼 주소입니다.

### 9-2.1 동작은 프런트가 구현합니다

**항공권 예약과 같은 방식**입니다. 생성기는 약속된 함수 호출만 넣고,
앱 판별·알림 설정·미설치 시 이동은 프런트에서 처리합니다.

```
<a … href="javascript:appAlarmSetting('https://abr.ge/uysf2c');">앱 알림 설정</a>
```

PC·모바일 구분 없이 같은 코드가 나가고, 별도 스크립트도 붙지 않습니다.

> ⚠️ **이 도구의 미리보기로는 동작을 검수할 수 없습니다.**
> `appAlarmSetting` 이 있는 실제 게시 페이지에서 확인해야 합니다.

## 10. 탭 기능 세 가지 — 무엇을 고를까

이름이 비슷해서 헷갈리기 쉽습니다. **동작이 완전히 다릅니다.**

| 기능               | 탭 메뉴                      | 콘텐츠          | 탭을 누르면        | 스크롤        |
| ------------------ | ---------------------------- | --------------- | ------------------ | ------------- |
| **탭 스크롤**      | 섹션마다 반복 (여러 벌)      | 전부 표시       | 해당 섹션으로 이동 | 이동함        |
| **스티키 탭**      | 문서에 하나 (화면 상단 고정) | 전부 표시       | 이동 + 자동 활성   | 이동함        |
| **탭 콘텐츠 전환** | 그룹마다 하나 (고정 아님)    | **선택된 것만** | 제자리에서 교체    | **안 움직임** |

**고르는 기준**

- 콘텐츠가 길고, 위로 스크롤해도 탭이 계속 보였으면 → **스티키 탭**
- 콘텐츠가 길고, 탭이 각 섹션 머리에 있으면 → **탭 스크롤**
- 콘텐츠를 한 번에 하나만 보여주고 싶으면 → **탭 콘텐츠 전환**

> 스티키 탭과 탭 콘텐츠 전환을 **동시에 켜면 탭 콘텐츠 전환이 우선**합니다.
> 둘 다 같은 범위를 감싸기 때문에 함께 쓸 수 없습니다.

## 11. 탭 스크롤

탭을 누르면 같은 페이지의 해당 섹션으로 이동합니다.

### 11.1 먼저 알아 둘 것

**탭 메뉴가 이미지에 그려져 있어야 합니다.** 그리고 관행상
**섹션마다 탭 메뉴가 반복**되므로, 각 섹션 이미지는
「탭 메뉴 + 콘텐츠」가 한 장으로 되어 있고 **활성 탭이 강조된 상태**여야 합니다.

그래서 탭이 N개면 **섹션 N개 × 탭 링크 N개**가 필요합니다.
탭 3개짜리라면 링크가 9개 생기는 것이 정상입니다.

### 11.2 사용법

**베네피아 / SKT** (통이미지)

1. **탭 개수**(2~6)를 넣고 `+ 탭 스크롤 세트 추가`
2. 섹션 마커와 탭 링크가 임시 위치에 생깁니다
3. 미리보기에서 **실제 탭 메뉴 위치로 옮깁니다**

**투어비스** (섹션 = 이미지)

1. 섹션 수만큼 이미지를 등록합니다
2. **탭 개수**와 **시작 이미지**를 지정하고 `+ 탭 스크롤 세트 추가`
3. 각 요소의 `영역 설정하기` 로 실제 위치를 잡습니다

**시작 이미지 = 탭 스크롤이 시작되는 첫 번째 이미지**입니다.

```
이미지 #1              → 탭과 무관한 상단 공통 영역
이미지 #2  ← 시작 이미지 → 탭 1 (섹션 a)
이미지 #3              → 탭 2 (섹션 b)
이미지 #4              → 탭과 무관한 하단 공통 영역
```

### 11.3 섹션 시작점은 '영역'이 아니라 '시작점'입니다

크기는 무시되고 **박스의 윗변**만 좌표로 쓰입니다.
탭을 눌렀을 때 화면 맨 위에 걸릴 지점 — 보통 **탭 메뉴 윗변**에 맞춥니다.

### 11.4 헤더 높이 보정

게시 페이지 위에 고정 헤더가 있으면 이동한 내용이 헤더에 가려집니다.
`헤더 높이 보정 스크립트 포함` 을 체크하고 헤더 높이(px)를 넣으면 그만큼 띄워 이동합니다.

> 스티키 탭을 쓸 때는 이 옵션이 아니라 **스티키 탭 패널 안의 헤더 높이 보정**을 씁니다.

## 12. 스티키 탭

스크롤하면 탭바가 화면 상단에 붙어 따라다니고, 위치에 따라 활성 탭이 자동으로 바뀝니다.
탭 스크롤과 달리 **탭 메뉴가 문서 전체에 하나뿐**입니다.

### 12.1 준비물 — 파일 이름 규칙

활성/비활성 탭 이미지를 **파일명 끝의 `_on` / `_off`** 로 구분해 준비합니다.

```
tab01_off.jpg   ← 도구에는 이것만 입력하면
tab01_on.jpg    ← 자동으로 유추합니다
```

> **입력은 하나지만 파일은 두 개가 필요합니다.**
> 도구는 주소의 파일명만 바꿔 볼 뿐이므로, `_on` 이미지도 **같은 경로에 실제로 올라가 있어야** 합니다.
> 없으면 활성 탭 자리가 깨진 이미지로 보입니다.

경로 중간에 `_` 가 있어도(`/my_promo_2024/img_tab_01_off.png`) 파일명 끝만 바꾸므로 안전합니다.

### 12.2 설정

| 항목           | 설명                                              |
| -------------- | ------------------------------------------------- |
| 탭바 ID        | 기본 `menu`                                       |
| 최대 폭        | **페이지 최대 폭과 같은 값**으로 맞춥니다         |
| 헤더 높이 보정 | 고정 헤더가 있을 때 그 높이. **0 이면 자동 측정** |

탭마다 넣는 값:

| 항목          | 설명                                |
| ------------- | ----------------------------------- |
| 섹션 ID       | `a`, `b` …                          |
| 시작 이미지   | **이 탭을 눌렀을 때 도착할 이미지** |
| 탭 이미지 URL | **비활성(`_off`) 주소만** 입력      |
| 대체 텍스트   | 이미지를 못 읽었을 때 표시될 글     |

### 12.3 시작 이미지가 구간을 나눕니다

```
이미지 #1        → 탭바 위 (상단 공통 영역, 어느 탭에도 속하지 않음)
──────── 탭바 ────────
이미지 #2, #3    → 탭 1 구간   (시작 이미지 = #2)
이미지 #4, #5    → 탭 2 구간   (시작 이미지 = #4)
```

탭 1 을 누르면 #2 로, 탭 2 를 누르면 #4 로 갑니다.
#3 은 따로 지정하지 않아도 탭 1 구간에 딸려 들어갑니다.

### 12.4 위치는 자동으로 맞습니다

탭바가 화면에 고정될 때, 도구가 **고정 직전의 실제 위치와 폭을 재서** 넣습니다.
그래서 게시 페이지의 본문에 좌우 여백이 있어도 탭바만 화면 끝까지 퍼지는 일이 없습니다.

## 13. 탭 콘텐츠 전환

탭을 누르면 **아래 콘텐츠가 교체**됩니다. **스크롤은 전혀 움직이지 않습니다.**

### 13.1 설정

**그룹**

| 항목           | 설명                                                       |
| -------------- | ---------------------------------------------------------- |
| 탭 버튼        | **텍스트**(글자 + 활성 색상) 또는 **이미지**(`_on`/`_off`) |
| 그룹 끝 이미지 | 이 그룹이 어디까지 차지하는지                              |

**탭마다**

| 항목                      | 설명                                   |
| ------------------------- | -------------------------------------- |
| 탭 이름 / 대체 텍스트     | 텍스트 모드는 화면에 표시되는 글자     |
| 시작 이미지               | 이 탭의 콘텐츠가 시작되는 이미지       |
| 활성 배경색 / 활성 글자색 | 텍스트 모드 전용                       |
| 탭 이미지 URL             | 이미지 모드 전용 — 비활성(`_off`) 주소 |

활성 탭 표시는 모드에 따라 다릅니다.

| 탭 버튼 모드 | 활성 표시                                           |
| ------------ | --------------------------------------------------- |
| 텍스트       | **배경색**(+ 글자색)이 바뀜                         |
| 이미지       | **`_off` → `_on`** 으로 교체 (해제되면 다시 `_off`) |

> 이미지 모드도 스티키 탭과 같습니다. **입력은 `_off` 하나지만 파일은 두 개** 필요합니다.

### 13.2 콘텐츠가 묶이는 방식

```
이미지 #1                    → 그룹 밖 (그대로 남음)
┌─ 탭 그룹 ───────────────────────────────
│  탭바
│  이미지 #2  → 탭 1 콘텐츠
│  이미지 #3  → 탭 2 콘텐츠   (그룹 끝 = #3)
└─────────────────────────────────────────
이미지 #4                    → 그룹 밖 (그대로 남음)
```

한 탭에 **이미지 여러 장**을 넣을 수 있습니다 — 다음 탭의 시작 이미지 직전까지가 한 탭입니다.
한 페이지에 **그룹을 여러 개** 둘 수도 있습니다.

> 탭 콘텐츠 안에 또 탭을 넣는 **이중 중첩은 지원하지 않습니다.**

## 16. 자주 묻는 질문

**Q. 작업하던 것이 새로고침하면 사라집니다.**
A. 현재는 저장 기능이 없습니다. 완성된 코드는 그때그때 복사해 두세요.

**Q. 이미지를 교체하면 좌표를 다시 잡아야 하나요?**
A. **가로세로 비율이 같으면 그대로** 쓸 수 있습니다. 좌표가 % 이기 때문입니다.

**Q. 탭 메뉴 이미지는 누가 만드나요?**
A. 디자인 단계에서 이미지 안에 그려져 있어야 합니다. 이 도구는 클릭 영역만 만듭니다.

**Q. PC 와 모바일 코드를 각각 만들어야 하나요?**
A. 투어비스는 플랫폼을 바꿔 각각 생성합니다. 좌표는 자동 환산되므로 다시 잡지 않아도 됩니다.

**Q. 이미지 사이에 영상을 통째로 넣고 싶습니다.**
A. 현재는 이미지 위에 겹치는 방식만 지원합니다.

**Q. 탭을 7개 이상 만들 수 있나요?**
A. 세트 추가는 2~6개까지입니다. 그 이상은 요소를 직접 추가해 만듭니다.
