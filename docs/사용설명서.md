# 프로모션 퍼블 자동 생성기 — 사용설명서

- 배포: https://pub-maker-drab.vercel.app/
- 로컬: `npm install` → `npm run dev` → http://localhost:5173

이 문서는 **기능점검 기준서**를 겸합니다. 각 절차대로 따라 했을 때 기대 결과가 나오는지 확인하고,
마지막 [§8 기능점검 체크리스트](#8-기능점검-체크리스트)에 결과를 기록하세요.

## 1. 먼저 알아야 할 것

### 1.1 세 개 탭의 차이

| 탭                     | 이미지 등록 관행                                      | 영역 지정 방식                                       | 출력 형태                                       |
| ---------------------- | ----------------------------------------------------- | ---------------------------------------------------- | ----------------------------------------------- |
| **투어비스(항공일반)** | 섹션마다 이미지를 **나눠서** 등록 (`pc_01`, `pc_02`…) | 요소마다 **영역 설정하기** → 매퍼 창에서 박스 드래그 | 완결된 HTML **문서** (`<!DOCTYPE html>` 포함)   |
| **베네피아/휴가샵**    | **통이미지 1장**에 좌표로 전부 배치                   | 미리보기 이미지 위에서 **직접 드래그**               | HTML **조각** (`<div class="content">`)         |
| **SKT**                | 통이미지 1장                                          | 미리보기 위에서 **직접 드래그**                      | HTML **조각** (`<div style="max-width:800px">`) |

> 세 탭 모두 이미지를 여러 장 등록할 수 있습니다. 위 구분은 **기능 제약이 아니라 작업 관행**입니다.

### 1.2 좌표는 모두 % 입니다

생성되는 좌표는 픽셀이 아니라 **이미지 대비 %** 입니다. 따라서 브라우저 폭이 바뀌어도
버튼 위치가 이미지와 함께 따라갑니다. 원본 이미지를 교체할 때 **가로세로 비율이 같으면**
좌표를 다시 잡지 않아도 됩니다.

### 1.3 미리보기와 코드 출력은 갱신 시점이 다릅니다

|             | 갱신 시점                                 |
| ----------- | ----------------------------------------- |
| 미리보기    | 입력할 때마다 **자동**                    |
| 코드 텍스트 | **`🚀 코드 생성하기`를 눌러야** 확정 갱신 |

작업이 끝나면 **반드시 `코드 생성하기`를 누른 뒤 `복사`** 하세요.

### 1.4 이미지 URL은 입력 후 반드시 포커스를 빼세요

URL 입력칸에서 **Tab 키를 누르거나 다른 곳을 클릭**해야 원본 이미지 크기를 읽어옵니다.
이 값은 **mp4 영상의 화면 비율 계산**과 좌표 환산에 쓰입니다. 입력만 하고 바로 영상을 추가하면
비율이 어긋날 수 있습니다.

## 2. 투어비스(항공일반) 탭

### 2.1 기본 흐름

1. **플랫폼 선택** — 💻 PC / 📱 모바일
   - 항공권 예약 버튼의 호출 함수가 달라집니다: PC `promoFixPop('코드')`, 모바일 `compactPopOpen('코드')`
   - **래퍼 규격이 플랫폼별로 다릅니다** (레퍼런스 `투어비스_항공\60492` 기준)

     ```
     [PC]
     <body>
       <div class="new-pb-container event-wrap"
            style="position: relative; width: 100%; max-width: 1200px; margin: 0 auto;">

     [모바일]
     <body style="margin: 0">
       <div class="new-pb-container event-wrap"
            style="position: relative; max-width: 900px; margin: auto; line-height: 0; overflow: hidden;">
     ```

     양쪽 모두 가운데 정렬입니다 — 넓은 화면에서 본문이 왼쪽으로 쏠리지 않게 합니다.
     모바일은 추가로 `line-height: 0` 으로 이미지 사이 틈을 없앱니다.

   - **최대 폭**은 플랫폼 선택 옆 입력칸에서 조정합니다 (기본 **PC 1200** / **모바일 900**)
     - **플랫폼별로 값을 따로 기억**합니다 — PC 를 1000 으로 바꾸고 모바일로 갔다 돌아와도 1000 유지
     - 좌우 여백은 `16.66667%` **비율**이라 최대 폭을 바꾸면 함께 줄고 늘어납니다.
       입력칸 옆에 그때의 이미지 실폭(최대 폭 × 2/3)이 표시됩니다
     - `초기화` 를 누르면 기본값으로 되돌아갑니다

   - PC + **배경색을 흰색이 아닌 값으로 지정한 경우에만** 좌우 여백
     `padding: 0 16.66667%` 이 붙습니다
     (레퍼런스의 `1200px 래퍼 + 200px` 을 비율로 옮긴 값 — 래퍼 폭이 달라져도 비율이 유지됩니다)
   - 여백이 붙으면 **오버레이의 가로 좌표가 자동 환산**됩니다.
     `position: absolute` 의 `%` 는 래퍼 **전체 폭**(여백 포함) 기준인데
     영역 설정 매퍼는 **이미지** 기준으로 좌표를 재기 때문입니다.
     세로(`bottom` · `height`)는 상하 여백이 없어 그대로 유지됩니다.

     |        | 좌우 여백 | 이미지 실폭 | 출력 좌표                |
     | ------ | --------- | ----------- | ------------------------ |
     | 모바일 | 없음      | 래퍼와 동일 | `left: 5%` `width: 90%`  |
     | PC     | 16.66667% | 래퍼의 2/3  | `left: 20%` `width: 60%` |

     같은 이미지·같은 위치인데 값이 다른 것이 **정상**입니다
     (레퍼런스 `투어비스_항공\60492` 와 동일한 결과).
2. **이미지 URL 입력** — `이미지 추가하기`로 필요한 만큼 행을 늘립니다
3. **배경색 지정**(선택) — 색상 피커 / HEX 직접 입력 / `스포이드`(Chrome 95+) / `이미지 색 추출`
4. **요소 추가** — 각 이미지 행 아래 4개 버튼

   | 버튼            | 생성되는 것                                     |
   | --------------- | ----------------------------------------------- |
   | `+ 버튼`        | 항공권 예약하기 / 앱 알림 설정 / 단순 링크      |
   | `+ 영상`        | 유튜브 iframe 또는 mp4 `<video>`                |
   | `+ 앵커 이동`   | `<a href="#섹션ID">` — 앵커 링크                |
   | `+ 섹션 시작점` | `<div class="section" id="…">` — 앵커 도착 지점 |

   > 뒤의 두 개는 **탭 스크롤을 이루는 부품**입니다. 탭 메뉴를 만들 때는
   > [§6.3](#63-앵커-이동--섹션-시작점-은-언제-직접-쓰나) 을 먼저 보세요.

5. **영역 설정하기** — 클릭하면 좌측 패널에 매퍼가 열립니다
   - 매퍼 제목에 **편집 중인 요소**가 표시됩니다 (`2. 영역 설정 — 요소 #2 · 앵커 이동 → #a`)
   - 박스를 **드래그해 이동**, **모서리 핸들로 크기 조절**
     (모서리를 두 번 클릭하는 방식이 아닙니다)
   - **`적용` 을 눌러야 저장**됩니다. 취소하거나 그냥 닫으면 반영되지 않습니다

   버튼 색으로 진행 상태를 알 수 있습니다.

   | 색      | 문구                       | 뜻                                                |
   | ------- | -------------------------- | ------------------------------------------------- |
   | 🟦 남색 | `영역 설정하기`            | 아직 좌표 없음 — 지정해야 코드 생성됨             |
   | 🟧 주황 | `📍 기본 영역 — 조정 필요` | 세트가 넣은 **기본 좌표** — 실제 위치로 옮겨야 함 |
   | 🟩 초록 | `✅ 영역 설정 완료`        | 매퍼에서 직접 지정하고 `적용` 까지 누름           |

   > 탭 스크롤 세트로 만든 요소는 좌표가 채워져 있어 코드 생성은 되지만
   > **위치는 임의값**입니다. 주황색이 남아 있으면 아직 손대지 않은 요소입니다.

6. **🚀 코드 생성하기** → `복사`

### 2.2 요소 타입별 입력값

| 타입                    | 입력값                                                |
| ----------------------- | ----------------------------------------------------- |
| 항공권 예약하기         | 항공사 코드 (예: `7C`, `KE`)                          |
| 앱 알림 설정            | 추가 입력값 없음 — 투어비스 앱의 알림 설정 화면 호출  |
| 단순 링크               | 연결 URL, 열기 방식(새 창 / 현재 페이지)              |
| 앵커 이동 (탭)          | 이동할 섹션 ID (예: `a`) — `#` 는 자동으로 제거됩니다 |
| 섹션 시작점 (앵커 대상) | 섹션 ID — **시작점(세로 위치)만** 사용, 크기는 무시   |
| 영상                    | [§5 영상 첨부](#5-영상-첨부) 참고                     |

### 2.3 주의사항

- **코드 생성 시 검증**이 돌아갑니다. 이미지 URL이 비었거나 좌표가 없는 요소가 있으면
  경고창이 뜨고 코드가 생성되지 않습니다.
- 요소를 **삭제해도 나머지 요소의 설정은 보존**됩니다(번호만 다시 매겨짐).
- `버튼 영역 시각화` 체크박스는 **미리보기에만** 빨간 점선을 그립니다. 복사되는 코드에는 들어가지 않습니다.

## 3. 베네피아/휴가샵 탭

### 3.1 편집은 오른쪽 미리보기에서 합니다

투어비스와 가장 헷갈리는 부분입니다.

| 탭             | 영역·앵커를 옮기는 곳                                     |
| -------------- | --------------------------------------------------------- |
| 투어비스       | **왼쪽 패널 아래**에 열리는 매퍼 창                       |
| 베네피아 / SKT | **오른쪽 미리보기 이미지 위** — 별도 창이 열리지 않습니다 |

왼쪽 목록에서는 **종류와 값만** 지정하고, **위치와 크기는 오른쪽에서** 맞춥니다.
버튼을 눌러도 왼쪽에 아무 창이 안 뜬다고 실패한 것이 아닙니다 — 오른쪽을 보세요.

### 3.2 기본 흐름

1. **`이미지 추가하기`** → 이미지 URL 입력 → **포커스 빼기**
2. 미리보기에 이미지가 뜨면 **이미지 위에서 드래그**해 영역을 그립니다
   - 가로·세로 모두 **10px 이상** 끌어야 영역이 생성됩니다
   - 생성된 영역은 **드래그로 이동**, **8방향 핸들로 크기 조절**, **× 버튼으로 삭제**
3. 좌측 `이미지맵 영역 추가` 목록에서 **영역 타입과 값**을 지정합니다
4. **🚀 코드 생성하기** → `코드 복사`

### 3.3 영역 타입

| 타입          | 출력                                                                                      |
| ------------- | ----------------------------------------------------------------------------------------- |
| 링크          | `<a href="…" target="…">`                                                                 |
| 쿠폰 다운로드 | `<a href="javascript:void(0)" onclick="couponDownloadAll(['id1','id2']); return false;">` |
| 앵커 이동     | `<a href="#섹션ID">`                                                                      |
| 영상          | 유튜브 iframe / mp4 `<video>`                                                             |

> 쿠폰 ID는 **쉼표로 구분**해 여러 개 입력할 수 있습니다. `couponDownloadAll` 함수는
> 게시 페이지 쪽에 이미 존재한다고 가정합니다(생성기가 만들지 않습니다).

### 3.4 앵커(섹션 마커)

- **`앵커 영역 설정`** 의 `+ 새 앵커 추가` → **오른쪽 미리보기 이미지 위**에 **빨간 핀**이 생깁니다
  (앵커는 클릭 영역이 아니라 **도착 지점**이라 `이미지맵 영역 추가` 에는 없습니다)
- 핀을 **위아래로 드래그**해 위치를 잡습니다
- 코드에는 **가로 전체 폭 / 높이 1px** 로 나가므로 **세로 위치만** 맞추면 됩니다
- 앵커 목록에서 ID를 바꿀 수 있습니다 (`#` 자동 제거)

### 3.5 이미지가 여러 장일 때

- 편집 오버레이(영역 박스·앵커 핀)는 **활성 이미지 1장에만** 표시됩니다
- 좌측 이미지 행을 **클릭하면 활성 이미지가 바뀝니다** (입력칸 클릭은 제외)
- 다른 이미지는 미리보기에 그대로 쌓여 보이기만 합니다

## 4. SKT 탭

베네피아와 조작 방식이 같습니다. 차이점만 정리합니다.

- 영역 타입: **링크 / 앵커 이동 / 탭 / 영상** (쿠폰 다운로드 없음)
- `탭` 타입은 `<a class="tab_item_admin skt-anchor-link" href="#탭ID">` 로 출력됩니다 (SKT 관리자 규격)
- 모든 링크에 `.skt-anchor-link` 클래스가 붙고, **투명화 스타일 블록이 문서 앞에 1회** 출력됩니다
- 출력 래퍼 폭은 `max-width: 800px`

## 5. 영상 첨부

이미지 위 원하는 위치에 **유튜브** 또는 **mp4** 영상을 겹쳐 넣습니다.

### 5.1 절차

| 탭             | 절차                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 투어비스       | 이미지 행에서 `+ 영상` → `영역 설정하기` 로 위치·크기 지정 → `적용` → URL 입력 |
| 베네피아 / SKT | `+ 영상` → 미리보기의 **VIDEO 박스**를 드래그·리사이즈 → URL 입력              |

### 5.2 입력값

| 항목                                   | 설명                                                                                                           |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 영상 종류                              | 유튜브 / MP4                                                                                                   |
| 영상 URL                               | 유튜브는 `watch?v=` · `youtu.be/` · `embed/` · `shorts/` 주소나 **11자리 ID** 모두 인식<br>MP4는 파일 직접 URL |
| 확대 비율 (%)                          | **MP4 전용.** 100 초과 시 영상 상하가 잘립니다 (세로 영역을 꽉 채울 때 사용)                                   |
| 자동재생 / 음소거 / 반복 / 컨트롤 표시 | 기본값: 자동재생·음소거·반복 ON, 컨트롤 OFF                                                                    |

### 5.3 알아둘 점

- **자동재생은 음소거가 켜져 있어야 동작합니다** (브라우저 정책). 자동재생만 켜고 음소거를 끄면 재생이 막힙니다.
- **유튜브 반복**은 `loop=1` 만으로는 동작하지 않아, 체크 시 `playlist=<영상ID>` 가 자동으로 함께 붙습니다.
- **MP4는 `aspect-ratio`** 로 비율이 고정됩니다. 이 값은 **이미지 원본 픽셀 크기**로 계산되므로
  [§1.4](#14-이미지-url은-입력-후-반드시-포커스를-빼세요) 대로 URL 입력 후 포커스를 빼야 정확합니다.
  원본 크기를 못 읽으면 `height: N%` 로 대체됩니다.
- 유튜브는 `aspect-ratio: 560/315` 로 고정되고 지정한 영역 안에서 **세로 중앙 정렬**됩니다.

## 6. 탭 스크롤

탭을 누르면 **같은 페이지 안의 다른 위치로 이동**하는 기능입니다. 탭바가 화면에 고정되지 않습니다.

### 6.1 핵심 개념 — 탭 메뉴는 섹션마다 반복됩니다

탭바가 고정되지 않으므로, 사용자가 어느 섹션에 있든 탭을 누를 수 있으려면
**섹션마다 탭 메뉴 이미지를 다시 넣어야** 합니다.

```
탭 N개  →  섹션 마커 N개  +  탭 링크 N × N 개
```

예) 탭 2개면 섹션 2개 + 링크 4개 (섹션 a 위치에 a·b 링크, 섹션 b 위치에 a·b 링크)

### 6.1-1 ⚠️ 준비물 — 이미지에 탭 메뉴가 그려져 있어야 합니다

탭 스크롤에서 생성기가 만드는 것은 **투명한 클릭 영역(`<a>`)과 섹션 시작점**뿐입니다.
**탭 메뉴 자체는 그리지 않습니다.**

따라서 이미지를 이렇게 준비해야 합니다.

```
┌──────────────────────────┐
│  [음악과 자연] 여유로운 휴식  │  ← 탭 메뉴가 이미지에 포함 (현재 탭이 강조된 상태)
├──────────────────────────┤
│                          │
│      섹션 a 콘텐츠         │
│                          │
└──────────────────────────┘
```

- **「탭 메뉴 + 콘텐츠」가 한 장**이어야 합니다
- 탭 메뉴가 **섹션마다 반복**되므로, 섹션 수만큼 이미지를 만들되
  **각 이미지에서 활성 탭이 다르게 강조**되어 있어야 합니다
- 투어비스는 섹션마다 이미지를 나눠 등록하고, 베네피아·SKT 는 통이미지 안에
  탭 메뉴가 반복 배치되어 있어야 합니다

> **다른 두 기능과의 차이**
>
> | 기능           | 탭 메뉴를 누가 만드나                        |
> | -------------- | -------------------------------------------- |
> | **탭 스크롤**  | **이미지에 포함** — 생성기는 클릭 영역만     |
> | 스티키 탭      | 생성기가 `<img>` 로 출력 (`_on`/`_off` 준비) |
> | 탭 콘텐츠 전환 | 생성기가 텍스트 또는 `<img>` 로 출력         |

### 6.1-2 섹션 마커는 "영역"이 아니라 "시작점"입니다

앵커 대상은 콘텐츠 영역 전체를 감싸는 게 아니라 **한 점**입니다.

```html
<div
  class="section"
  id="a"
  style="position:absolute; left:0; top:16.07%; width:100%; height:1px;"
></div>
```

- 앵커 이동은 대상 요소의 **윗변이 화면 상단에 오도록** 스크롤하므로 **높이는 무의미**합니다
- 가로는 항상 전체 폭이라 **x 좌표도 의미 없습니다** — `top` 하나만 쓰입니다
- 투어비스에서 `영역 설정하기`로 박스를 그려도 **박스의 윗변 위치만** 저장됩니다
  (그래서 버튼 문구가 `세로 위치 설정하기` 로 바뀝니다)

**어디에 두나?** 레퍼런스 55457 을 보면 섹션 마커와 그 자리 탭메뉴의 `top` 이 **같습니다**.

```html
<div class="section" id="a" style="… top:16.07% …">
  ← 섹션 a 시작점
  <a href="#a" style="… top:16.07%; left:5.5%; …"> ← 섹션 a 위치의 탭메뉴</a>
</div>
```

탭을 눌러 이동했을 때 **탭메뉴가 화면 맨 위에 걸리도록** 맞추는 것이 관행입니다.
세트 추가 시 기본 배치도 이렇게 정렬되어 있습니다.

### 6.2 사용법

**베네피아 / SKT** (통이미지)

1. 이미지 등록 후 `탭 스크롤` 영역에서 **탭 개수** 입력 (2~6)
2. `+ 탭 스크롤 세트 추가`
3. 섹션 마커 N개가 세로 균등 배치되고, **각 섹션 위치에 탭 링크 한 벌**이 가로 균등으로 생깁니다
4. 미리보기에서 핀과 박스를 **실제 탭 메뉴 이미지 위치로 옮깁니다**

**투어비스** (섹션 = 이미지)

1. 섹션 수만큼 이미지를 등록합니다
2. **탭 개수**와 **시작 이미지**를 지정 → `+ 탭 스크롤 세트 추가`
3. 시작 이미지부터 N장에 각각 `섹션 마커 1개 + 탭 메뉴 한 벌`이 생성됩니다
4. 각 요소의 `영역 설정하기`로 실제 위치를 잡습니다

**시작 이미지 = 탭 스크롤이 시작되는 첫 번째 이미지**입니다.
이 이미지가 **탭 1(섹션 a)** 이 되고, 다음 이미지가 탭 2(섹션 b) … 순으로 이어집니다.

```
이미지 #1              → 탭과 무관한 상단 공통 영역
이미지 #2  ← 시작 이미지 → 탭 1 (섹션 a)
이미지 #3              → 탭 2 (섹션 b)
이미지 #4              → 탭과 무관한 하단 공통 영역
```

> 시작 이미지부터 남은 장수가 탭 개수보다 적으면 생성하지 않고 안내창이 뜹니다.

### 6.3 `앵커 이동` · `섹션 시작점` 은 언제 직접 쓰나

이 두 요소는 **탭 스크롤을 이루는 부품**입니다. `세트 추가` 는 이 둘을
탭 개수만큼 한꺼번에 만들어 주는 단축 버튼일 뿐, 다른 것을 만들지 않습니다.

| 만들려는 것                             | 쓸 것                                   |
| --------------------------------------- | --------------------------------------- |
| 탭 메뉴 (링크 N벌 + 도착 지점 N개)      | **`세트 추가`** — 하나씩 만들 필요 없음 |
| 낱개 앵커 (예: "혜택 보러가기 ↓", TOP)  | `+ 앵커 이동` + `+ 섹션 시작점`         |
| 세트가 만든 탭에 링크 한 개만 더 붙이기 | `+ 앵커 이동`                           |
| 스티키 탭                               | **아무것도 필요 없음**                  |

**스티키 탭**은 탭바의 링크와 도착 지점(`<div id="…" class="tab-area">`)을
스스로 만들기 때문에 앵커·섹션을 따로 추가하면 **ID가 겹쳐 오히려 오작동**합니다.
[§7 스티키 탭](#7-스티키-탭)의 설정만 쓰세요.

### 6.4 헤더 높이 보정

게시되는 페이지 상단에 **고정 헤더**가 있으면 앵커로 이동했을 때 내용이 헤더에 가려집니다.
`헤더 높이 보정 스크립트 포함` 을 체크하고 헤더 높이(px)를 입력하면,
그만큼 위로 띄워 이동하는 스크립트가 코드에 함께 출력됩니다.

> 스티키 탭을 켜면 이 옵션은 무시됩니다. 스티키 탭은 보정을 직접 처리하므로
> **스티키 탭 패널 안의 `헤더 높이 보정 (px)`** 을 쓰세요 ([§7.2](#72-사용법) 참고).

## 7. 스티키 탭

스크롤하면 **탭바가 화면 상단에 붙어 따라다니고**, 현재 위치에 따라 **활성 탭 이미지가 자동 전환**됩니다.
탭 스크롤과 달리 **탭 메뉴가 문서 전체에 하나뿐**입니다.

### 7.1 준비물 — 탭 이미지 파일명 규칙

활성/비활성 이미지를 **파일명 끝의 `_on` / `_off`** 로 구분해 준비합니다.

```
tab01_off.jpg   ← 생성기에는 이것만 입력하면
tab01_on.jpg    ← 자동으로 유추합니다
```

> ⚠️ **입력은 하나지만, 파일은 두 개가 필요합니다.**
> 생성기는 `_off` 주소의 파일명만 바꿔 `_on` 주소를 만들 뿐이므로,
> **`_on` 이미지도 같은 경로에 실제로 올라가 있어야** 활성 전환이 보입니다.
> 없으면 활성 탭 자리가 깨진 이미지로 보입니다.

> 규칙에 맞지 않는 파일명이면 이미지 전환이 동작하지 않습니다.
> 경로 중간에 `_` 가 있어도(`/my_promo_2024/img_tab_01_off.png`) 파일명 끝만 바꾸므로 안전합니다.

### 7.2 사용법

1. `스티키 탭 사용` 체크
2. `탭바 ID`(기본 `menu`) · `최대 폭`(px) · `헤더 높이 보정`(px) 확인

   > ⚠️ **최대 폭은 페이지 최대 폭과 같은 값**이어야 합니다.
   > 투어비스라면 상단 `최대 폭 (PC)` 입력값(기본 1200), 베네피아는 1180, SKT 는 800 입니다.
   > 값이 다르면 탭바만 본문보다 넓거나 좁아 보입니다.

   좌우 **위치**는 신경 쓰지 않아도 됩니다. `position: fixed` 는 뷰포트 기준이라
   `left: 0; right: 0` 으로 두면 `body` 나 바깥 컨테이너의 `padding`·`margin` 을 무시하고
   화면 끝까지 퍼지는데, 스크립트가 **고정되기 직전의 실제 위치와 폭을 재서** 넣기 때문에
   어떤 여백이 있어도 본문과 축이 맞습니다.

   **헤더 높이 보정**은 게시 페이지 상단에 **고정 헤더(GNB)** 가 있을 때 그 높이를 넣습니다.
   탭 스크롤의 [§6.4 헤더 높이 보정](#64-헤더-높이-보정)과 같은 목적이지만,
   스티키 탭은 자체 스크립트로 처리하므로 **여기에 따로 입력**해야 합니다.
   보정값은 두 곳에 쓰입니다.

   | 쓰이는 곳       | 효과                                         |
   | --------------- | -------------------------------------------- |
   | 탭바 고정 위치  | 화면 맨 위가 아니라 **헤더 아래**에 붙습니다 |
   | 탭 클릭 시 이동 | 헤더 + 탭바 높이만큼 여유를 두고 멈춥니다    |

   > **0 이면 자동 측정**합니다 — `header` → `.content-header` → `.sub-page-tit-area` 순으로
   > 찾아 그 높이를 씁니다. 게시 페이지의 헤더가 이 셀렉터에 걸리지 않거나
   > 헤더가 없으면 그때 값을 직접 넣으세요.

3. `+ 탭 추가` 를 탭 수만큼 누르고, 각 탭에 입력:

   | 항목          | 설명                                                |
   | ------------- | --------------------------------------------------- |
   | 섹션 ID       | `a`, `b` … 앵커 ID                                  |
   | 시작 이미지   | **이 탭을 눌렀을 때 도착할 이미지** (아래 7.3 참고) |
   | 탭 이미지 URL | **비활성(`_off`) 주소만** 입력 (`_on` 은 자동 유추) |
   | 대체 텍스트   | `alt` 속성                                          |

4. `🚀 코드 생성하기`

### 7.3 시작 이미지 = 그 탭이 도착할 이미지

**시작 이미지**는 "이 탭을 눌렀을 때 화면이 멈출 이미지"입니다.
거기서부터 **다음 탭의 시작 이미지 직전까지**가 그 탭의 구간(`.tab-area`)이 됩니다.

```
이미지 #1        → 탭바 위 (상단 공통 영역, 어느 탭에도 속하지 않음)
──────── 탭바 ────────
이미지 #2, #3    → <div id="a" class="tab-area">   탭1 · 시작 이미지 = #2
이미지 #4, #5    → <div id="b" class="tab-area">   탭2 · 시작 이미지 = #4
```

- 탭1 을 누르면 **#2 로**, 탭2 를 누르면 **#4 로** 이동합니다
- #3 은 따로 지정하지 않아도 탭1 구간에 딸려 들어갑니다
- 첫 탭의 시작 이미지 **앞**에 있는 이미지는 탭과 무관한 상단 공통 영역으로 남습니다
- 스크롤로 그 구간에 들어가면 해당 탭이 자동으로 `_on` 으로 바뀝니다

> **URL이 입력된 이미지만** 번호에 포함됩니다. 빈 행은 세지 않습니다.

### 7.4 미리보기 제약

- **투어비스**는 iframe 미리보기라 스티키 동작까지 확인할 수 있습니다
- **베네피아 / SKT**는 편집용 오버레이 화면이라 **탭바가 미리보기에 나타나지 않습니다.**
  코드 출력으로만 확인되며, 실제 동작은 붙여넣은 페이지에서 확인해야 합니다

## 7-2. 탭 콘텐츠 전환

탭을 누르면 **아래 이미지 콘텐츠가 바뀝니다**. 앵커 이동이 아니므로 **스크롤은 전혀 움직이지 않습니다**
(레퍼런스: `투어비스_호텔\51714`).

### 7-2.1 세 가지 탭 기능 비교

| 기능               | 탭메뉴                       | 콘텐츠          | 클릭 시             | 스크롤        |
| ------------------ | ---------------------------- | --------------- | ------------------- | ------------- |
| 탭 스크롤          | 섹션마다 반복 (N벌)          | 전부 표시       | 앵커로 **이동**     | 이동함        |
| 스티키 탭          | 문서에 1개 (스크롤 고정)     | 전부 표시       | 이동 + 자동 활성    | 이동함        |
| **탭 콘텐츠 전환** | **그룹마다 1개** (고정 아님) | **선택된 것만** | 제자리에서 **교체** | **안 움직임** |

활성 탭 표시는 모드에 따라 다릅니다.

| 탭 버튼 모드 | 활성 표시                                                      |
| ------------ | -------------------------------------------------------------- |
| 텍스트       | **배경색**(+ 글자색) 이 `li:nth-child(n).on a` 규칙으로 바뀜   |
| 이미지       | 이미지가 **`_off` → `_on`** 으로 교체됨 (선택 해제되면 `_off`) |

### 7-2.2 사용법

1. `+ 탭 그룹 추가` — 한 페이지에 **그룹을 여러 개** 만들 수 있습니다
   (51714 는 3탭 그룹 + 2탭 그룹 = 2개)
2. 그룹 설정

   | 항목           | 설명                                                                 |
   | -------------- | -------------------------------------------------------------------- |
   | 탭 버튼        | **텍스트**(라벨 + 활성 색상) 또는 **이미지**(`_on`/`_off` 자동 유추) |
   | 그룹 끝 이미지 | 이 그룹이 **어디까지** 차지하는지                                    |

3. 탭마다 설정

   | 항목                      | 설명                                      |
   | ------------------------- | ----------------------------------------- |
   | 탭 이름 / 대체 텍스트     | 텍스트 모드는 화면에 표시되는 문구        |
   | 시작 이미지               | 이 탭의 콘텐츠가 시작되는 이미지          |
   | 활성 배경색 / 활성 글자색 | 텍스트 모드 전용 (`li:nth-child(n).on a`) |
   | 탭 이미지 URL             | 이미지 모드 전용 — 비활성(`_off`) 주소    |

   > ⚠️ 이미지 모드도 스티키 탭과 같습니다. **입력은 `_off` 하나지만 파일은 두 개** 필요합니다 —
   > 선택된 탭이 `_on` 으로 교체되므로 같은 경로에 `_on` 이미지가 실제로 올라가 있어야 합니다.

4. `🚀 코드 생성하기`

### 7-2.3 콘텐츠가 어떻게 묶이는지

```
이미지 #1                    → 그룹 밖 (그대로 남음)
┌─ tab-switch ────────────────────────────────
│  탭바 (음악과 자연 / 여유로운 휴식)
│  이미지 #2  → <div class="tabCont on">   (탭1 시작 이미지 = #2)
│  이미지 #3  → <div class="tabCont">      (탭2 시작 이미지 = #3, 그룹 끝 = #3)
└─────────────────────────────────────────────
이미지 #4                    → 그룹 밖 (그대로 남음)
```

한 탭에 **이미지 여러 장**을 넣을 수도 있습니다 — 다음 탭의 시작 이미지 직전까지가 한 탭입니다.

### 7-2.4 주의사항

- **스티키 탭과 동시에 켜면 탭 콘텐츠 전환이 우선**합니다. 두 기능 모두 같은 블록 범위를
  감싸므로 함께 적용할 수 없습니다. 스티키 탭바는 출력되지 않습니다.
- 베네피아·SKT 는 편집용 미리보기라 탭바가 화면에 렌더되지 않습니다 (코드 출력으로만 확인).
- **탭 콘텐츠 안에 또 탭을 넣는 이중 중첩은 지원 범위 밖**입니다. 레퍼런스(51714)와 동일하게
  그룹 안의 `.tabCont` 를 전부 대상으로 삼으므로, 중첩하면 안쪽 탭까지 함께 잡힙니다.

## 8. 기능점검 체크리스트

`npm run dev` 로 띄운 뒤 순서대로 확인하세요. 실제 접근 가능한 이미지 URL이 필요합니다.

### 8.1 기본 동작

- [ ] 상단 3개 탭 전환이 정상 동작한다
- [ ] 각 탭 `초기화` 버튼이 이미지·영역·스티키 탭 설정·보정 옵션까지 모두 되돌린다
- [ ] `복사` 버튼으로 코드가 클립보드에 들어간다

### 8.2 투어비스

- [ ] 플랫폼을 PC ↔ 모바일로 바꾸면 예약 버튼 함수가 `promoFixPop` ↔ `compactPopOpen` 으로 바뀐다
- [ ] 배경색을 흰색이 아닌 값으로 지정하고 PC를 선택하면 `padding: 0 16.66667%` 이 붙는다
- [ ] 배경색이 흰색(기본)이면 `padding` 이 붙지 않는다
- [ ] PC 래퍼: `width: 100%; max-width: 1200px` / `<body>`
- [ ] 모바일 래퍼: `max-width: 900px; margin: auto; line-height: 0; overflow: hidden` / `<body style="margin: 0">`
- [ ] 플랫폼을 바꾸면 **미리보기가 즉시 갱신**된다
- [ ] `최대 폭` 입력값이 래퍼 `max-width` 에 반영된다
- [ ] 최대 폭을 PC/모바일 각각 다르게 넣어도 **플랫폼별로 값이 유지**된다
- [ ] 최대 폭을 바꾸면 옆의 이미지 실폭 힌트(× 2/3)도 함께 바뀐다
- [ ] `초기화` 후 최대 폭이 기본값(PC 1200)으로 돌아온다
- [ ] 같은 좌표로 잡은 버튼이 모바일 `left: 5% / width: 90%` → PC `left: 20% / width: 60%` 로 환산된다
- [ ] `bottom` · `height` 는 PC/모바일이 동일하다 (세로는 환산하지 않음)
- [ ] 배경색이 흰색이면 PC라도 환산하지 않는다
- [ ] **브라우저 확인** — PC + 배경색 상태에서 `버튼 영역 시각화` 를 켰을 때
      점선 영역이 **이미지 안에 정확히 들어맞는다** (좌우 여백까지 번지지 않음)
- [ ] 매퍼 안내가 **드래그·핸들 방식**으로 되어 있다 (두 번 클릭 방식이 아니다)
- [ ] 매퍼 제목에 편집 중인 요소가 표시된다 (`2. 영역 설정 — 요소 #1 …`)
- [ ] `+ 버튼` 으로 만든 요소는 처음엔 `영역 설정하기`(남색)이다
- [ ] `영역 설정하기` → 박스 이동/리사이즈 → `적용` 후 버튼이 `✅ 영역 설정 완료`(초록)로 바뀐다
- [ ] `적용` 후 매퍼가 닫히고 **미리보기가 갱신**된다
- [ ] 완료 표시는 이미지 URL·요소 타입을 바꿔도 **유지**된다
- [ ] 이미지를 불러오지 못한 상태로 `적용` 을 누르면 **조용히 넘어가지 않고 안내창**이 뜬다
- [ ] 탭 스크롤 세트로 만든 요소는 `📍 기본 영역 — 조정 필요`(주황)로 표시되고 **완료로 보이지 않는다**
- [ ] 섹션 시작점은 문구가 `세로 위치` 로 나온다
- [ ] 좌표를 지정하지 않은 요소가 있으면 코드 생성 시 경고가 뜬다
- [ ] 요소를 삭제해도 **다른 요소의 타입/URL 설정이 유지**된다
- [ ] `버튼 영역 시각화` 를 꺼도 **복사되는 코드는 동일**하다

### 8.3 베네피아 / SKT

- [ ] 미리보기 이미지 위 드래그로 영역이 생성된다 (10px 미만은 무시)
- [ ] 영역을 드래그로 옮기고 8방향 핸들로 크기를 조절할 수 있다
- [ ] 영역의 `×` 버튼과 목록의 `삭제` 버튼 모두 동작한다
- [ ] 이미지가 여러 장일 때 좌측 행을 클릭하면 **활성 이미지가 전환**된다
- [ ] 베네피아: 쿠폰 ID를 쉼표로 여러 개 넣으면 `couponDownloadAll(['a','b'])` 로 나온다
- [ ] SKT: 투명화 스타일 블록이 **이미지 수와 무관하게 1회만** 출력된다
- [ ] 이미지 행에 배경색 입력칸이 없다 (투어비스 전용 기능)
- [ ] `이미지맵 영역 추가` 에 **앵커 추가 버튼이 없다** — 두 탭 모두 `앵커 영역 설정` 한 곳뿐
- [ ] `+ 새 앵커 추가` 로 앵커가 정상 생성된다
- [ ] 코드 생성 버튼 문구가 `생성 완료` → 다시 `🚀 코드 생성하기` 로 복원된다

### 8.4 탭 스크롤

- [ ] 패널에 "이미지에 탭 메뉴가 이미 그려져 있어야 합니다" 안내가 보인다

- [ ] 탭 개수 N으로 세트를 추가하면 **섹션 N개 + 링크 N×N개**가 생성된다
- [ ] 섹션 마커가 `left:0; width:100%; height:1px` 로 출력된다
- [ ] 앵커 핀을 드래그하면 섹션의 `top%` 가 따라 바뀐다
- [ ] 섹션 시작점의 크기를 바꿔도 출력은 `width:100%; height:1px` 로 고정된다
- [ ] 투어비스: 요소 제목에 종류·대상 ID 가 표시된다 (`요소 #2 · 앵커 이동 → #a`)
- [ ] 투어비스: 남은 이미지가 탭 개수보다 적으면 **생성하지 않고** 안내창이 뜬다
- [ ] 투어비스: 시작 이미지부터 N장에 각각 섹션 1개 + 탭메뉴 한 벌이 들어간다

- [ ] **브라우저 확인** — 코드를 붙여넣고 탭을 누르면 해당 섹션으로 부드럽게 이동한다
- [ ] **브라우저 확인** — 창 폭을 바꿔도 이동 지점이 어긋나지 않는다
- [ ] 헤더 보정 옵션을 켜고 값을 넣으면 `var OFFSET = 값;` 스크립트가 붙는다

### 8.5 스티키 탭

- [ ] 최대 폭 옆에 **"페이지 최대 폭과 맞추라"** 는 안내가 보인다
- [ ] 탭 URL 아래에 **`_on` 이미지도 실제로 있어야 한다**는 안내가 보인다
- [ ] 시작 이미지 아래에 **"이 탭을 눌렀을 때 도착할 이미지"** 라는 안내가 보인다
- [ ] `_off` URL만 넣어도 첫 탭이 `_on` 으로 출력된다
- [ ] 경로 중간에 `_` 가 있는 URL도 파일명 끝만 정확히 치환된다
- [ ] `시작 이미지` 대로 `.tab-area` 구간이 나뉜다
- [ ] 탭바 앞 이미지는 `.tab-area` 밖(상단 공통 영역)에 남는다
- [ ] **브라우저 확인** — 탭바 최대 폭을 페이지 최대 폭과 같게 두면 좌우 축이 맞는다
- [ ] **브라우저 확인** — `body` 나 컨테이너에 좌우 `padding`·`margin` 이 있어도

- [ ] **브라우저 확인** — 창 폭을 바꾼 뒤에도 고정 탭바의 좌우가 다시 맞는다
- [ ] **브라우저 확인** — 스크롤 시 탭바가 상단에 고정되고 **레이아웃이 튀지 않는다**
- [ ] **브라우저 확인** — 스크롤 위치에 따라 활성 탭 이미지가 `_on` 으로 바뀐다
- [ ] **브라우저 확인** — 탭을 누르면 탭바 높이만큼 여유를 두고 해당 구간으로 이동한다
- [ ] `헤더 높이 보정` 기본값 0 이면 `var HEADER_OFFSET = 0;` 이고 자동 측정 코드가 남아 있다
- [ ] 값을 넣으면 `var HEADER_OFFSET = 값;` 으로 바뀌고 **자동 측정보다 우선**한다
- [ ] **브라우저 확인** — 고정 헤더가 있는 페이지에서 탭바가 **헤더 아래**에 붙는다

## 10. 문제 해결

| 증상                                | 원인 / 조치                                                                         |
| ----------------------------------- | ----------------------------------------------------------------------------------- |
| 미리보기에 이미지가 안 뜬다         | URL이 `https://` 로 시작하는 **이미지 직접 링크**인지 확인. CORS 차단일 수 있습니다 |
| 영역을 그려도 안 만들어진다         | 가로·세로 **10px 이상** 드래그해야 합니다                                           |
| "이미지가 아직 로드되지 않았습니다" | 이미지 로딩 전에 세트/앵커를 추가한 경우. 이미지가 보인 뒤 다시 시도하세요          |
| MP4 비율이 이상하다                 | 이미지 URL 입력 후 **포커스를 빼지 않아** 원본 크기를 못 읽은 경우                  |
| 유튜브가 반복되지 않는다            | `반복` 체크 여부 확인. `playlist` 파라미터가 붙어야 동작합니다                      |
| 자동재생이 안 된다                  | **음소거**가 켜져 있어야 브라우저가 자동재생을 허용합니다                           |
| 스티키 탭 이미지가 안 바뀐다        | 파일명이 `_on` / `_off` 규칙인지 확인                                               |
| 활성 탭이 깨진 이미지로 보인다      | `_on` 파일이 서버에 없는 경우. 입력은 `_off` 하나지만 **파일은 두 개** 필요합니다   |
| 탭바가 본문보다 넓거나 좁다         | 스티키 탭 `최대 폭` 을 **페이지 최대 폭과 같은 값**으로 맞추세요                    |
| 앵커로 이동했는데 헤더에 가린다     | `헤더 높이 보정 스크립트 포함` 체크 후 헤더 높이(px) 입력                           |
| 스티키 탭인데 헤더에 가린다         | 이 옵션은 무시됩니다. **스티키 탭 패널의 `헤더 높이 보정`** 에 넣으세요             |
| 탭바가 고정 헤더에 파묻힌다         | 스티키 탭 `헤더 높이 보정` 이 0(자동 측정)인데 헤더를 못 잡은 경우. 값을 직접 입력  |
| 코드가 갱신되지 않는다              | `🚀 코드 생성하기` 를 눌렀는지 확인                                                 |
| 복사가 안 된다                      | 코드 textarea를 클릭 후 `Ctrl+A` → `Ctrl+C`                                         |
