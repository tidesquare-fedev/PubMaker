## 1. 배경

현재 생성기는 3개 탭(투어비스 항공일반 / 베네피아·휴가샵 / SKT)으로 구성되어 있고,

실제 운영 퍼블에서 반복적으로 쓰이지만 생성기가 못 만드는 마크업이 3가지 있어 수작업으로 처리 중이다.

## 2. 레퍼런스 마크업 분석

### 2.1 탭 스크롤 — 베네피아 55457

```html
<div style="position:relative; max-width: 1180px; margin: 0 auto;">
  <img src="images/55457.jpg" style="border:0; max-width: 100%;" />

  <!-- 섹션 마커: 가로 전체, 높이 1px, top만 % 로 지정 -->
  <div
    class="section"
    id="a"
    style="position:absolute; left:0; top:16.07%;  width:100%; height:1px;"
  ></div>
  <div
    class="section"
    id="b"
    style="position:absolute; left:0; top:55.415%; width:100%; height:1px;"
  ></div>

  <!-- 탭 클릭 영역: 같은 탭 세트를 섹션마다 반복 배치 -->
  <a
    style="position:absolute; top:16.07%; left:5.5%;  width:44.5%; height:0.83%; text-indent:-9999px;"
    href="#a"
  ></a>
  <a
    style="position:absolute; top:16.07%; right:5.5%; width:44.5%; height:0.83%; text-indent:-9999px;"
    href="#b"
  ></a>
</div>
```

**핵심 포인트**

- 앵커 대상(`#a`, `#b`)은 **가로 전체 폭 / 높이 1px** 의 `div.section` — x좌표는 의미 없고 **y(top%)만** 필요.
- 탭 링크는 일반 오버레이 `<a>` 와 동일하지만 `href="#섹션ID"`.
- **탭 메뉴 이미지가 섹션마다 반복된다** (`<!--tab1-->`, `<!--tab2-->`).
  스티키 탭이 아니면 탭바가 화면에 고정되지 않으므로, 사용자가 어느 섹션에 있든
  탭을 누를 수 있도록 **섹션마다 탭 메뉴 한 벌을 다시 그려 넣는 것**이 관행이다.
  → 탭 N개일 때 **섹션 마커 N개 + 탭 링크 N×N 개**가 필요하다.
  (위 예시: 섹션 2개 × 탭 링크 2개 = `<a>` 4개)
- 부드러운 이동을 위해 `html { scroll-behavior: smooth; }` 필요(58693에 존재).

> **스티키 탭과의 차이**
> 스티키 탭은 탭바가 스크롤을 따라다니므로 **탭 메뉴가 문서 전체에 하나뿐**이다.
> 탭 스크롤은 탭 메뉴가 **섹션 수만큼 반복**된다. 이것이 두 기능의 본질적 차이다.

**현재 코드와의 차이**

- `benefia.js` / `skt.js` 는 이미 앵커 핀(`<div id="..">`)과 `href="#.."` 오버레이를 만든다.
- 다만 앵커 div 를 `left:X%; width:1px; height:1px` 로 **점**으로 생성 → x좌표가 무의미하게 코드에 남고, 브라우저 폭에 따라 오차 발생.
- smooth scroll 스타일 / 헤더 높이 보정 스크립트가 없음.

### 2.2 스티키 탭 — 투어비스 58693

```html
<style>
  html {
    scroll-behavior: smooth;
  }
  .event-wrap .fix {
    position: fixed !important;
    top: 0;
    z-index: 1;
    width: 100%;
    max-width: 800px;
  }
  .event-wrap .tab-box ul li a {
    display: block;
  }
</style>

<div
  class="event-wrap"
  style="position:relative; max-width:800px; margin:auto;"
>
  ... 상단 이미지 ...

  <div id="menu" class="tab-box" style="position:relative; z-index:5;">
    <ul
      class="on-off"
      style="display:flex; justify-content:space-between; width:100%; margin:0; padding:0; list-style:none;"
    >
      <li class="on" style="width:50%">
        <a href="#a" class="tab-btn"
          ><img src=".../tab01_on.jpg" alt="하우스텐보스란?"
        /></a>
      </li>
      <li style="width:50%">
        <a href="#b" class="tab-btn"
          ><img src=".../tab02_off.jpg" alt="추천 여행 코스"
        /></a>
      </li>
    </ul>
  </div>

  <div style="position:relative">
    <div id="a" class="tab-area">...탭1 콘텐츠 이미지들...</div>
    <div id="b" class="tab-area">...탭2 콘텐츠 이미지들...</div>
  </div>

  ... 하단 공통 이미지 ...
</div>
```

**스크립트가 하는 일 (원본 요약)**

1. `#menu` 의 원래 y좌표를 기억 → 스크롤이 그 지점을 넘으면 `.fix` 클래스 부여 (`position:fixed`).
2. 헤더(`header`, `.sub-page-tit-area`, `.content-header`)가 있으면 그 높이만큼 `top` 을 내림.
3. `.tab-area` 들의 y 위치 배열을 만들어, 현재 스크롤 위치에 해당하는 탭을 활성화.
4. 활성화 = `li.on` 클래스 + `<img>` 의 `_off.jpg` ↔ `_on.jpg` **파일명 치환**.
5. 탭 클릭 시 `preventDefault` 후 `탭바 높이 + 헤더 높이` 를 뺀 위치로 `scrollTo`.

**원본 스크립트의 개선 대상**

| 문제                                                                                     | 개선안                                                         |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `evtWrap.style.marginTop = menu.clientHeight` 로 전체 래퍼를 밀어 상단 이미지까지 움직임 | 탭바 자리에 **스페이서 div** 를 삽입해 레이아웃 점프 제거      |
| `src.split('_')[0]` 로 on/off 치환 → URL 경로에 `_` 가 있으면 깨짐                       | 정규식 `/_(on\|off)(\.확장자)(\?쿼리)?$/` 로 **끝부분만** 치환 |
| `setTimeout(500)` 의존 / `sectionArray` 전역 누수                                        | IIFE + `load`/`resize` 시 재측정                               |
| jQuery·Swiper 의존 코드와 뒤섞임                                                         | 탭 로직만 **바닐라 JS** 로 분리 출력                           |
| 인라인 `onclick="btnClickAction(this)"` (전역 함수 필요)                                 | `#menu` 에 이벤트 위임으로 바인딩                              |

### 2.3 영상 첨부 — 투어비스 항공

**유튜브 (PC)**

```html
<div
  style="position:absolute; width:61.66666%; left:19.16666%; height:8.2786%; top:14.36815%"
>
  <iframe
    style="position:absolute; width:100%; left:0; aspect-ratio:560/315; top:50%; transform:translateY(-50%)"
    src="https://www.youtube.com/embed/6JHW52IOr2Q?autoplay=1&mute=1&loop=1&playlist=6JHW52IOr2Q"
    title="YouTube video player"
    frameborder="0"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
    referrerpolicy="strict-origin-when-cross-origin"
    allowfullscreen
  ></iframe>
</div>
```

- 바깥 div = 이미지 위 **%좌표 박스**(버튼 영역과 동일한 좌표계).
- iframe 은 `aspect-ratio: 560/315` 를 유지한 채 세로 중앙 정렬.
- `loop=1` 은 반드시 `playlist=<동일 ID>` 와 세트여야 동작.

**mp4 (모바일)**

```html
<div
  style="position:absolute; width:53.25%; left:23.5%; aspect-ratio:426/756; top:13.5739%; overflow:hidden"
>
  <div
    class="emped-vide"
    style="position:absolute; width:100%; height:180%; top:50%; left:0; right:0; transform:translateY(-50%)"
  >
    <video autoplay loop muted playsinline style="width:100%; height:100%">
      <source src=".../movie_m_01.mp4" type="video/mp4" />
    </video>
  </div>
</div>
```

- 바깥 div 는 `height%` 대신 **`aspect-ratio: 가로px/세로px`** 로 비율 고정 (반응형에서 안정적).
- 안쪽 `height:180%` + `overflow:hidden` = 영상 상하를 **잘라내는 확대 비율**.

**전체 폭 영상 (58693)** — `.embed-box` + `<video controls autoplay muted loop playsinline style="width:100%">`.
→ 이번 범위(오버레이)에는 미포함, 3단계 확장 항목으로 보류.

## 3. 설계 방향

### 3.1 공통 모듈화

3개 탭에 동일 기능을 넣되 **코드 3중 복사를 피하기 위해** 신규 파일 `js/features.js` 를 만든다.
현재 `benefia.js` 와 `skt.js` 는 이미 90% 중복 상태이므로, 신규 기능만이라도 단일 소스로 유지한다.

```
js/
  common.js     (기존: 클립보드 / HEX / 탭 전환)
  features.js   (신규: 탭 스크롤 · 스티키 탭 · 영상 코드 생성 + UI 헬퍼)   ← 순수 함수 위주
  tourism.js    (수정)
  benefia.js    (수정)
  skt.js        (수정)
```

`features.js` 는 전역 `PubFeatures` 네임스페이스 하나만 노출한다.

| 구분     | API                                           | 설명                                                                         |
| -------- | --------------------------------------------- | ---------------------------------------------------------------------------- |
| 공통     | `toPctRect(area, nW, nH)`                     | 픽셀/비율 좌표 → `{left, top, width, height}` % 문자열 (기존 중복 로직 통합) |
| 영상     | `parseYoutubeId(input)`                       | URL(watch/youtu.be/embed/shorts) 또는 11자 ID → ID                           |
| 영상     | `buildVideoOverlay(video, rect, natural)`     | 유튜브 iframe / mp4 video 오버레이 HTML                                      |
| 탭스크롤 | `buildSectionMarker(id, topPct)`              | `div.section` 마커 HTML                                                      |
| 탭스크롤 | `SMOOTH_SCROLL_STYLE`                         | `html{scroll-behavior:smooth}`                                               |
| 탭스크롤 | `buildAnchorOffsetScript(offsetPx)`           | 헤더 높이 보정 스크롤 스크립트 (옵션)                                        |
| 스티키탭 | `swapOnOff(url, 'on'\|'off')`                 | 파일명 끝 `_on`/`_off` 안전 치환                                             |
| 스티키탭 | `buildStickyTabStyle(maxWidth)`               | `.fix` 등 스타일 블록                                                        |
| 스티키탭 | `buildStickyTabBar(cfg)`                      | `#menu > ul.on-off > li > a > img` 마크업                                    |
| 스티키탭 | `buildStickyTabScript(cfg)`                   | 고정/활성전환/클릭이동 바닐라 스크립트                                       |
| UI       | `renderStickyTabPanel(root, state, onChange)` | 3개 탭이 공유하는 스티키 탭 설정 패널 렌더러                                 |
| UI       | `renderVideoFields(area)`                     | 영상 입력 필드 HTML (종류/URL/옵션)                                          |

### 3.2 기능별 구현 방식

#### (1) 탭 스크롤

공통 원칙: **탭 개수 N → 섹션 마커 N개 + 탭 링크 N×N 개** (섹션마다 탭 메뉴 한 벌).

- **베네피아 / SKT** — 통이미지 1장에 좌표로 배치하는 관행
  - 기존 "앵커 추가"(보라 핀) 를 **섹션 마커**로 승격: 코드 생성 시 `left:0; width:100%; height:1px; class="section"` 으로 출력.
    (핀의 x좌표는 편집 편의용으로만 유지, 출력에서 제거 → 반응형 오차 제거)
  - 신규 **"＋ 탭 스크롤 세트"** 버튼: 탭 개수 N 입력 →
    섹션 마커 N개를 세로로 균등 배치하고, **각 섹션 y 위치에 탭 링크 N개(가로 균등)** 를 함께 생성.
  - 출력 코드 상단에 `SMOOTH_SCROLL_STYLE` 1회 삽입.
  - 옵션 체크박스 "헤더 높이 보정 스크립트 포함" → `buildAnchorOffsetScript`.
- **투어비스** — 섹션마다 이미지를 나눠 등록하는 관행
  - 버튼 타입 select 에 `앵커 이동`, `섹션(앵커 대상)`, `영상` 추가 + 이미지 행마다 전용 추가 버튼.
  - `섹션` 타입은 기존 "영역 설정" 매퍼로 위치를 잡되 **top% 만** 사용해 `div.section` 출력.
  - **"＋ 탭 스크롤 세트"**: `탭 개수 N` + `시작 이미지` → 시작 이미지부터 **N장**에
    각각 `섹션 마커 1개(최상단) + 탭 메뉴 한 벌(링크 N개)` 을 배치.
    남은 이미지가 N장보다 적으면 생성하지 않고 안내한다.

#### (2) 스티키 탭

3개 탭 공통으로 좌측 패널 하단에 설정 블록 추가.

```
☑ 스티키 탭 사용
  탭바 컨테이너 ID : menu           최대 폭 : 800px
  ┌ 탭 #1  섹션ID [a]  탭 이미지(off) URL [ .../tab01_off.jpg ]  시작 이미지 [#3 ▾] ┐
  ┌ 탭 #2  섹션ID [b]  탭 이미지(off) URL [ .../tab02_off.jpg ]  시작 이미지 [#5 ▾] ┐
  [+ 탭 추가]
```

- **on/off 이미지**: `_off` URL 하나만 입력받고, 활성 이미지는 `_on` 으로 **자동 유추**(사용자 선택 결과).
  최초 렌더 시 1번 탭만 `_on`, 나머지 `_off` 로 출력하고 이후 전환은 스크립트가 처리.
- **섹션 구성**: "시작 이미지" 로 이미지 목록을 구간 분할.
  - `시작 이미지 #1` 앞의 이미지 → 상단 공통 영역 (탭바 위)
  - 탭 i 시작 ~ 탭 i+1 시작 직전 → `<div id="섹션ID" class="tab-area">` 로 감쌈
  - 마지막 탭 구간 이후 → 하단 공통 영역
- 출력: 스타일 블록 + 탭바 + `.tab-area` 래핑 + 스크립트.
- 미리보기: 투어비스는 iframe 미리보기라 **실제 동작까지 확인 가능**. 베네피아/SKT 는 DOM 오버레이 편집기라 탭바가 미리보기에 렌더되지 않으므로, 패널에 "코드 출력에만 반영" 안내 문구를 표시.

#### (3) 영상 첨부

- **베네피아 / SKT**: 영역 타입에 `video` 추가 → 드래그·리사이즈 인프라를 그대로 재사용.
  - 미리보기에서 파란 `VIDEO` 박스로 표시 (`.benefia-video-box` / `.skt-video-box`).
  - 입력 필드: 종류(유튜브/MP4) · URL · 확대비율(%) · 자동재생 / 음소거 / 반복 / 컨트롤 표시.
- **투어비스**: 버튼 타입에 `영상` 추가 → 기존 "영역 설정" 매퍼로 %좌표 지정.
  - mp4 `aspect-ratio` 계산을 위해 `saveSelectionToRow()` 에 `top`, `wPx`, `hPx` 를 추가 저장.
- **코드 생성 규칙**
  - 유튜브: `?autoplay=1&mute=1&loop=1&playlist=<ID>&controls=0` 를 체크박스 상태에 따라 조립. `loop` 선택 시 `playlist` 자동 동반.
  - mp4: 바깥 div 는 `aspect-ratio:<가로px>/<세로px>` (자연 크기 미확보 시 `height:H%` 로 폴백), 안쪽 div `height:<확대비율>%`.
