# 스크린샷 촬영 목록

`사용가이드-원고.md` 의 `[스크린샷 N]` 자리에 넣을 화면 12장입니다.

- 촬영 화면: http://localhost:5173/ (또는 https://pub-maker-drab.vercel.app/)
- 파일 이름: `01.png` … `12.png` — 번호가 원고의 `[스크린샷 N]` 과 일치합니다

## 촬영 전 준비

**브라우저 폭을 1400px 정도**로 맞추면 좌우 패널이 나란히 보입니다.
좁으면 위아래로 쌓여 캡처가 길어집니다.

**샘플 이미지 URL** 을 미리 준비하세요. 실제 프로모션 이미지가 가장 좋습니다.
없으면 세로로 긴 이미지 아무거나 3~4장이면 충분합니다.

**브라우저 확대는 100%** 로 두세요. 여러 장의 글자 크기가 들쭉날쭉해집니다.

가이드에 남으면 곤란한 **실제 URL·쿠폰 ID·항공사 코드**는 촬영 전에 예시 값으로 바꿔 두세요.

## 촬영 목록

### 01 · 전체 화면

- **탭**: 투어비스(항공일반)
- **상태**: 첫 진입 그대로 (입력 없음)
- **범위**: 상단 탭 ~ 좌우 패널이 모두 보이게
- **의도**: 도구가 어떻게 생겼는지 첫인상

### 02 · 이미지를 넣은 상태

- **준비**: 이미지 URL 입력 → **다른 곳 클릭**(포커스 빼기)
- **범위**: 왼쪽 이미지 정보 입력 + 오른쪽 미리보기
- **의도**: URL 하나로 미리보기가 뜬다는 것

### 03 · 영역 설정 매퍼

- **준비**: `+ 버튼` → `영역 설정하기` → 박스를 **실제 버튼 자리로** 드래그
- **범위**: 매퍼 제목(`2. 영역 설정 — 요소 #1 …`)부터 `적용`/`취소` 버튼까지
- **의도**: 드래그·핸들 방식이라는 것. **제목의 요소 이름이 보이게** 찍어 주세요

### 04 · 영역 설정 완료

- **준비**: 03 에서 `적용` 을 누른 직후
- **범위**: 요소 상자 (초록색 `✅ 영역 설정 완료` 버튼이 잘 보이게)
- **의도**: 적용해야 저장된다는 것

### 05 · 생성된 코드

- **준비**: 요소 타입·값을 채우고 `🚀 코드 생성하기`
- **범위**: 오른쪽 `생성된 코드` 영역
- **의도**: 최종 결과물의 모습

### 06 · 왼쪽 설정 패널 전체

- **탭**: 베네피아 (블록이 6개라 구분선이 가장 잘 보입니다)
- **준비**: 이미지 1장 등록
- **범위**: `1. 설정` 부터 `🚀 코드 생성하기` 까지 (세로로 긴 캡처)
- **의도**: 기능 블록이 구분선으로 나뉘어 있다는 것
- **팁**: 전체 페이지 캡처 기능을 쓰세요 (개발자도구 → `Capture full size screenshot`)

### 07 · 세 가지 버튼 색

- **탭**: 투어비스
- **준비**:
  1. 이미지 2장 등록
  2. `탭 스크롤` 에서 탭 개수 `2` → `+ 탭 스크롤 세트 추가` → **주황** 요소들이 생깁니다
  3. 그중 하나만 `영역 설정하기` → `적용` → **초록**
  4. `+ 버튼` 을 하나 더 눌러 **남색** 을 만듭니다
- **범위**: 세 색이 한 화면에 보이게
- **의도**: 진행 상태를 색으로 읽는 법

### 08 · 좌우 여백과 클릭 영역

- **탭**: 투어비스 · 플랫폼 `PC`
- **준비**:
  1. 배경색을 **흰색이 아닌 색**(예: 주황)으로 지정
  2. 버튼 요소의 영역을 실제 버튼 위치에 맞춰 지정
  3. 오른쪽 `버튼 영역 시각화` 체크
- **범위**: 미리보기 (좌우 배경색 여백 + 빨간 점선 영역이 함께 보이게)
- **의도**: 여백이 생겨도 클릭 영역이 이미지 안에 정확히 들어맞는다는 것

### 09 · 영상 설정

- **탭**: 베네피아 (입력칸이 한눈에 들어옵니다)
- **준비**: `+ 영상` → 유튜브 URL 입력. **MP4 로 바꾼 화면도 한 장** 더
- **범위**: 영상 설정 입력칸 (종류 / URL / 체크박스 4개, MP4 는 확대 비율까지)
- **의도**: 유튜브와 MP4 의 입력 항목 차이
- **비고**: 두 장을 나란히 붙여 한 장으로 만들면 비교가 쉽습니다

### 10 · 탭 스크롤 설정

- **탭**: 투어비스
- **준비**: 이미지 3장 등록 → `탭 스크롤` 블록이 보이는 위치로 스크롤
- **범위**: 블록 전체 (⚠️ 주황 경고문, 탭 개수, 시작 이미지, 설명문까지)
- **의도**: 이미지에 탭 메뉴가 있어야 한다는 경고와 시작 이미지 개념

### 11 · 스티키 탭 설정

- **탭**: 투어비스 (또는 베네피아)
- **준비**:
  1. `스티키 탭 사용` 체크
  2. `+ 탭 추가` 2번
  3. 첫 탭 URL 에 `https://.../tab01_off.jpg` 같은 예시 주소 입력
- **범위**: 블록 전체 (⚠️ 최대 폭 경고, 헤더 높이 보정 설명, `_on` 자동 유추 안내까지)
- **의도**: 입력은 `_off` 하나지만 파일은 두 개라는 것

### 12 · 탭 콘텐츠 전환 설정

- **탭**: 투어비스 (또는 베네피아)
- **준비**: 이미지 3장 등록 → `+ 탭 그룹 추가` → 탭 2개가 기본 생성됩니다
- **범위**: 블록 전체 (그룹 설정 + 탭 2개 + 하단 설명문)
- **의도**: 그룹과 탭의 관계

## 있으면 좋은 추가 컷

원고에 자리를 만들어 두지는 않았지만, 넣으면 이해가 크게 쉬워집니다.

| 화면                    | 촬영 방법                                                             |
| ----------------------- | --------------------------------------------------------------------- |
| **탭 스크롤 실제 동작** | 생성한 코드를 브라우저에서 열고, 탭을 누르기 전후 2컷                 |
| **스티키 탭 고정 순간** | 스크롤해서 탭바가 상단에 붙은 상태 (활성 탭이 `_on` 인 것이 보이게)   |
| **탭 콘텐츠 전환 전후** | 탭 1 선택 / 탭 2 선택 각각 1컷 — **스크롤 위치가 같다는 점**이 보이게 |

| 파일                        | 역할                                      |
| --------------------------- | ----------------------------------------- |
| `docs/사용가이드-원고.md`   | **본문 원고** — 이것이 PDF 의 내용        |
| `01.png` ~ `12.png`         | 원고의 `[스크린샷 N]` 자리에 들어갈 화면  |
| `docs/스크린샷-촬영목록.md` | (선택) 각 이미지가 무엇인지 설명하는 참고 |

프롬프트 예시:

```
첨부한 '사용가이드-원고.md' 를 사내 배포용 PDF 사용 가이드로 만들어 주세요.

- 본문의 [스크린샷 N] 표시 자리에 같은 번호의 이미지를 넣어 주세요
- 표와 코드 블록의 서식은 그대로 살려 주세요
- 표지에 제목과 작성일을 넣고, 목차를 만들어 주세요
- 내용을 새로 지어내지 말고 원고에 있는 것만 사용해 주세요
```

마지막 줄이 중요합니다. 없으면 없는 기능을 그럴듯하게 지어내는 경우가 있습니다.
받은 결과물은 **§14 자주 하는 실수**와 **§15 용어** 표가 원고와 같은지 한 번 대조해 보세요.
