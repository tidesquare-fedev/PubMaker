2. 버튼 영역 설정

이미지 위의 파란 박스를 드래그해 위치를 잡고, 모서리 핸들로 크기를 맞춘 뒤 적용을 누르세요. 적용해야 저장되고, 해당 요소의 버튼이 ✅ 영역 설정 완료로 바뀝니다.

탭 스크롤

탭 메뉴 이미지는 섹션마다 반복되므로, 시작 이미지부터 탭 개수(N)만큼의 이미지에 각각 섹션 마커 1개 + 탭 링크 N개 = N+1개의 요소가 생성됩니다.
예) 탭 2개 · 시작 이미지 #2 → 이미지 #2 와 #3 에 각각 요소 3개. 생성 후 각 요소의 영역 설정하기로 위치만 잡아주세요.

⚠️ 이미지에 탭 메뉴가 이미 그려져 있어야 합니다. 생성기는 투명한 클릭 영역만 만들고 탭 메뉴를 그리지 않습니다. 각 섹션 이미지는 「탭 메뉴 + 콘텐츠」가 한 장으로 되어 있어야 하며, 활성 탭이 강조된 상태로 섹션마다 따로 제작해야 합니다.

시작 이미지 = 탭 스크롤이 시작되는 첫 번째 이미지입니다. 이 이미지가 탭 1(섹션 a)이 되고, 바로 다음 이미지가 탭 2(섹션 b), 그다음이 탭 3… 순으로 이어집니다. 앞쪽 이미지는 탭과 무관한 상단 공통 영역으로 남습니다.

스티키 탭

탭 콘텐츠 전환

탭을 누르면 제자리에서 콘텐츠가 교체됩니다 (스크롤 이동 없음). 스티키 탭과 동시에 켜면 탭 콘텐츠 전환이 우선합니다.

이미지맵 영역 추가

버튼을 누르면 오른쪽 미리보기 이미지 위에 영역 상자가 생깁니다. 위치와 크기는 거기서 드래그·핸들로 맞추고, 아래 목록에서는 종류와 값만 지정합니다.
미리보기 이미지 위에서 직접 드래그해 새 영역을 그릴 수도 있습니다.

앵커 영역 설정

앵커는 같은 페이지 내 이동 지점입니다. 영역이 아니라 시작점이라 코드에는 width:100%; height:1px 로 나갑니다 — 세로 위치만 맞추면 되고, 보통 탭메뉴 윗변에 맞춥니다.
+ 새 앵커 추가를 누르면 오른쪽 미리보기 이미지 위에 빨간 핀이 나타납니다. 그 핀을 위아래로 드래그해 위치를 잡으세요 (보라색 점선이 실제 이동 지점).

탭 스크롤

탭 메뉴는 섹션마다 반복되므로 섹션 N개 × 탭 링크 N개가 생성됩니다. 생성 후 미리보기에서 위치만 잡아주세요.

⚠️ 이미지에 탭 메뉴가 이미 그려져 있어야 합니다. 생성기는 투명한 클릭 영역만 만들고 탭 메뉴를 그리지 않습니다. 통이미지 안에 섹션마다 탭 메뉴가 반복되어 있어야 하며, 각 위치에서 활성 탭이 강조된 상태로 제작해야 합니다.

스티키 탭

탭 콘텐츠 전환

탭을 누르면 제자리에서 콘텐츠가 교체됩니다 (스크롤 이동 없음). 스티키 탭과 동시에 켜면 탭 콘텐츠 전환이 우선합니다.
